# Unsub 0.7.0 — draft, not released

- **Linux packages.** AppImage and Debian packages for x86_64, with bundled audio codecs. Ubuntu 22.04/24.04 and Debian 12 are the validation targets.
- **Copy videos from an iPod.** Choose **Copy Videos…** on its Summary to save movies, music videos and other video records to a folder, together with a metadata report. Original files stay unchanged, including protected files; copying does not remove protection. This adds export, not video playback or video syncing.
- **Artwork view fixes.** Album Artwork groups normalized and compilation albums consistently, recovers from missing covers and keeps row geometry aligned. It now uses your saved song columns and horizontal scrolling.
- **Better Cover Flow.** Selection follows the active song, remains stable when filtering, and supports keyboard navigation while rendering a bounded number of covers.

These notes describe the upcoming changes. Public 0.6.0 downloads remain unchanged. Linux desktop update transitions, physical iPod video recovery and actual High Sierra execution still need hardware/runtime validation before claiming support for those paths.
