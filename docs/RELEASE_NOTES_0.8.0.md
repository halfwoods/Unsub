# Unsub 0.8.0

- **Add videos to an iPod.** Choose **Add Videos…** on a supported iPod’s Summary to copy compatible local movies or music videos without conversion. Review compatibility and space before adding; existing music, playlists and artwork are preserved. Physical iPod playback remains unverified.
- **Playing indicator follows the music.** When a song ends and the next begins automatically, the speaker indicator now moves to the correct song in the list, including gapless playback.
- **Window size is remembered.** Unsub restores your window dimensions and maximized state after a restart. Quitting while minimized or in full screen preserves your normal window size.

This patch includes the features and fixes from 0.7.0. Linux support and Intel High Sierra compatibility remain experimental. Installed Linux desktop updates and administrator prompts (PolicyKit), physical Linux audio hardware and actual High Sierra execution remain unverified; use the release downloads if in-app updating is unavailable.

Unsub is free software under GPL-3.0-or-later. Bundled FFmpeg, LAME and Opus remain separate, replaceable libraries; their source archives are included with this release.
